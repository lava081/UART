# 编译选项说明

## 指令

### 编译

```sh
make
```

### 清理编译结果

```sh
make clean
```

`Rebuild` = 清理编译结果 + 编译

## Makefile变量

### TARGET

生成的可执行文件名

### DEBUG

编译结果可调试

### OPT

编译选项

#### -O

`-O0`, `-O1`, `-O2`, `-O3`, `-Og`, `-Os`

> 优化选项：`-O0`关闭优化，`-Og`调试友好型优化，`-Os`代码尺寸最小优化

#### -std=

`c89`, `c99`, `c11`, `c17`, `c23`

> c语言标准：默认为`c89`

### BUILD_DIR

输出文件夹

### C_SOURCES

`.c`源文件，以` \`分隔

> 请确保你在此处添加了所有待编译的`.c`源文件

> `\`的含义是，忽略换行符，下一行应当认为与本行处在同一行之上

### C_INCLUDES

`.h`声明文件目录，以`-I`开头，以` \`分隔

> 请确保你在此处添加了所有待包含的`.h`声明文件所在的目录
